% Figure (Section 4.1, a): the architecture of Reverb in an AI-RAN server and the procedure for a failed TB.  Running
% example: three failed TBs A, B and C.  (1) the L1 decodes every slot and the received samples of a slot with a failed TB
% stay in GPU memory; (2) Recovery Gate: A and C failed few code blocks (at most K) and wait, B failed all ten and the
% base station requests its retransmission at once; (3) Receiver Selector: the cell of C has interference above theta
% and uses the interference-trained NRx, the others the published NRx; (4) Recovery Scheduler: earliest deadline first,
% one recovery per GPU, and a TB that cannot start by D - r is rejected; (5) each GPU decodes its TB again from the
% stored samples between the L1 slots, in time that AI inference used; (6) the L2 scheduler delivers a decoded TB and
% sends the grant of any other.  No measured value appears (Design section rule).
