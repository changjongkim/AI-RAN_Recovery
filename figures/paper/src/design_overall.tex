% Figure (Section 4.1, a): the architecture of Reverb in an AI-RAN server and the procedure for a failed TB, drawn in
% rows as in the STATOR figures.  Cells: the uplink slots of cells A, B and C.  L1: the result of each TB as its ten code
% blocks (green decoded, red failed), and the received samples of a slot with a failed TB, kept in GPU memory.  Reverb:
% Recovery Gate (wait when at most K code blocks failed), Receiver Selector (the cell's interference against theta),
% Recovery Scheduler (failed TBs in deadline order, each started by D - r).  GPUs: the time of each GPU, with the L1 of
% every slot, recoveries and AI inference in the rest.  L2 Scheduler: a decoded TB is delivered, any other gets its grant.
% Red arrows carry failed TBs, green arrows decoded TBs.  No measured value appears (Design section rule).
