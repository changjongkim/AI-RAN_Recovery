% Figure (Section 4.1): the architecture of Reverb in an AI-RAN server and the procedure for one failed TB.
% (1) the fronthaul samples of every slot land in GPU memory and the L1 decodes them; (2) for a TB whose CRC fails, the
% Recovery Gate decides from the failed code blocks whether the base station waits for the recovery; (3) the Receiver
% Selector picks the receiver by the interference of the cell; (4) the Recovery Scheduler places the recovery on a GPU in
% deadline order, or rejects it when it cannot start by its latest start time; (5) the receiver decodes the TB again from
% the stored samples; (6) the result goes to the L2 scheduler: a decoded TB is delivered, any other gets its grant.
% No measured value appears (Design section rule).
