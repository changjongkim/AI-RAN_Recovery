% Shared TikZ style of the Reverb paper figures (2026-10-29, third version).  The look of the deck figures
% (figures/deck/src/tikz_style2.tex) at the size of the one-column page, in the font of the data panels:
%   - DejaVu Sans everywhere (make_paper_figures.py and the STATOR data panels use it), built with LuaLaTeX
%   - bold only for the names of panels and components; every other text in the regular weight
%   - what exists without Reverb (L1, L2 scheduler, GPUs, AI inference, the conventional receiver) is gray: gray
%     panel, gray border, gray text (existing); what Reverb adds is orange: orange panel and border, black text (rev)
%   - state is drawn as rows of cells (cl), tables with a blue header row (th) where a table is needed
%   - red (dred) only for failed code blocks, retransmissions, missed deadlines and the key note of a figure
% One colour per entity in every figure: uplink slot teal, special slot gray, L1 gray, AI light blue, received samples
% violet, NRx trained without interference light orange, NRx trained with interference dark orange (the two NRx
% colours of the data panels).  Canvas: at most 13.9 cm wide (the text width), and as low as the content allows.
% No text or mark crosses the border of a box it does not belong to.  The PDFs carry no date or id.

% A TB as its ten code blocks: \cbs{x}{y}{failed}{pitch}{height} (left end x, centre y; failed blocks red).
\newcommand{\cbs}[5]{%
  \foreach \i in {1,...,10} {
    \pgfmathsetmacro{\f}{ifthenelse(\i <= #3, 1, 0)}
    \ifdim \f pt = 1pt \def\fc{dred}\else\def\fc{white}\fi
    \draw[black!60, line width=0.3pt, fill=\fc] ({#1 + #4*(\i-1)}, {#2 - #5/2}) rectangle ({#1 + #4*\i - 0.03}, {#2 + #5/2});
  }}
