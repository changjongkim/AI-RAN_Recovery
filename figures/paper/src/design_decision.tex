% the base station holds its grant and waits for the recovery; TB B failed all 10, so the base station requests the
% retransmission at once and the recovery runs only when a GPU has time (a decoded TB ends before its retransmission is
% decoded).  K is the gate threshold (Latency-Neutral; Full Wait waits for every failed TB).  (b) Receiver Selector:
% each cell measures the interference over thermal of its slots; a cell above the threshold theta uses the
% interference-trained NRx, a cell below it the published NRx.  No measured value appears (Design section rule).
